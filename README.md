# Redes de Computadores — Cisco Packet Tracer

Projeto destinado ao armazenamento de estudos e simulações desenvolvidos durante a graduação em Engenharia da Computação.

Este repositório reúne topologias, configurações e documentação relacionada a infraestrutura de redes e protocolos de roteamento.

## Conteúdos abordados

- Endereçamento IPv4
- Subnetting
- Modelo OSI
- RIP
- OSPF
- Wildcard Mask
- Configuração de roteadores
- Simulações no Cisco Packet Tracer

## Tecnologias

- Cisco Packet Tracer

## Objetivo

Aplicar conceitos teóricos de redes de computadores em ambientes simulados, desenvolvendo conhecimento prático sobre roteamento e infraestrutura.
